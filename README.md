# Rationenplaner

A static website that helps farmers to put together and optimise recipes with good nutritional values for pig feed, 
and to calculate supplementary feed.

---
❗ You are taking a *sneak peek* at the next version. It could be that some features you find on this page are not
released yet.  
Please have a look at the README of the corresponding release/git tag. Latest
version: [README of v0.1.0](https://github.com/fibl/rationenplaner/tree/main/README.md).

# Installation

You can navigate to `domain needs to be defined by FiBL` to access the web-app, no installation required. 
Download the static website if you want to use it offline/run on your own machine.

# Contributors and contribute

Our thanks go to [code contributors](https://github.com/fibl/rationenplaner/graphs/contributors)
as well as all other contributors (e.g. bug reporters, feature request creators etc.)

You are more than welcome to contribute as well:

- star this repository if you like/use it
- [open a bug](https://github.com/fibl/rationenplaner/issues/new?template=bug_report.md) if you find one
- Open a [new discussion](https://github.com/fibl/rationenplaner/discussions/new?category=ideas) if you
  are missing a
  feature
- [ask a question](https://github.com/fibl/rationenplaner/discussions/new?category=q-a)
  so that we better understand where we can improve.
- have a look at
  the [help wanted issues](https://github.com/fibl/rationenplaner/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22).

Please have a look at
[CONTRIBUTING.md](https://github.com/fibl/rationenplaner/tree/main/.github/CONTRIBUTING.md)
for further suggestions and guidelines.
